#

Verificação de integridade SHA-256

Calcule o hash de um arquivo e compare com uma referência. SHA-256 é um resumo criptográfico, não criptografia de dados.

Nenhum arquivo selecionado.
O resultado aparecerá aqui.
Comandos para Windows e Linux
Windows PowerShell
Get-FileHash -Path "C:\arquivo.zip" -Algorithm SHA256
Linux
sha256sum arquivo.zip

Inspeção de XML Sintaxe e estrutura

Confira se o arquivo XML é bem formado, identifique elemento raiz e namespace. Não valida XSD, assinatura ou legislação.
