ETAPA 01

Verifique a permissão de acesso

A publicação exige uma conta com autorização de escrita no repositório lts-unochapeco/LTS-0092-GIT-WEB-PAGES-LTS ↗. Se você tiver apenas permissão de leitura, solicite acesso ao administrador.

ETAPA 02

Instale os arquivos sem apagar o conteúdo existente

  1. Baixe o pacote LTS_Ferramentas_Pages_v1.1.zip e extraia-o.
  2. Clone o repositório GitHub para sua máquina.
  3. Copie a pasta extraída para a raiz, preservando diretórios e documentos que já existam.
  4. Confira os arquivos novos e envie as alterações com git add, git commit e git push. 
git clone https://github.com/lts-unochapeco/LTS-0092-GIT-WEB-PAGES-LTS.git
cd LTS-0092-GIT-WEB-PAGES-LTS
# Copie os arquivos extraídos do ZIP para a pasta acima.
git status --short
git add index.html guia.html .nojekyll assets apps GUIA_PUBLICACAO_LTS.md INTEGRACAO_SITE_LTS.html TEMA_ATLAS_E_JEKYLL.md tests
git commit -m "feat: portal de ferramentas LTS v1.1"
git push origin main

O repositório pode ter branch protegida; nesse caso, abra um Pull Request conforme as regras locais.

ETAPA 03

Configure o GitHub Pages

  1. Abra Settings → Pages.
  2. Em Build and deployment, escolha Deploy from a branch.
  3. Defina o branch em uso (geralmente main) e a pasta /(root).
  4. Salve e teste o portal, o editor e a rota /?embed=1.
Sobre o tema Atlas: o portal utiliza HTML/CSS/JS próprios e o arquivo .nojekyll. Não precisa de theme: Atlas nem de outro tema Jekyll.

ETAPA 04

Incorpore no menu Ferramentas

No site lts.unochapeco.edu.br, adicione um link externo ou um bloco HTML com iframe apontando para a URL com ?embed=1:

<iframe title="Central de Ferramentas LTS"
 src="https://lts-unochapeco.github.io/LTS-0092-GIT-WEB-PAGES-LTS/?embed=1"
 style="width:100%;min-height:1400px;border:0"
 loading="lazy"></iframe>

O arquivo INTEGRACAO_SITE_LTS.html contém uma alternativa com ajuste de altura. Se o CMS ou CSP bloquear iframe, mantenha um link externo.

ETAPA 05

Planeje a emissão oficial DTC / LCL

O editor entregue gera somente minutas XML não oficiais. Para assinar e emitir LCL com validade institucional, ainda são necessários XSD e leiaute homologados, validação de requisitos, controle de acesso, assinatura XMLDSig / ICP-Brasil conforme regulamentação e uma trilha de auditoria em backend seguro.

Consulte os Atos DIAT nº 54/2026 e nº 56/2026 e suas atualizações na página oficial SEF/SC — NFC-e ↗.
