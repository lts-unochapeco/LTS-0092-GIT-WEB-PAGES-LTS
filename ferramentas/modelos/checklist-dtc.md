# Checklist de preparação — DTC — Diagnóstico Técnico de Conformidade

Material de apoio. Não é instrumento contratual, documento oficial ou laudo. Valide contra o procedimento vigente. Não publique este arquivo preenchido.

## Escopo
Avaliação diagnóstica de aderência do software a requisitos aplicáveis, destinada a identificar lacunas e orientar adequações. Não substitui LCL nem homologação.

## Verificações
- [ ] Identificação do aplicativo e versão
- [ ] base de requisitos
- [ ] roteiro de testes
- [ ] evidências
- [ ] não conformidades
- [ ] recomendações
- [ ] relatório diagnóstico
- [ ] Confirmar permissões, confidencialidade e responsabilidades
- [ ] Registrar origem, versão, data e responsável pelas evidências
- [ ] Verificar necessidade de revisão, aceite e entrega autorizada
